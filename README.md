# milloin

Kevyt Doodle-klooni omaan käyttöön. Ehdota muutamaa aikaa, jaa linkki, katso mikä sopii kaikille.

## Miksi

Doodle on hyvä, mutta maksullinen, mainostettu ja säilöö dataa jonnekin. Tämä on sama idea ilman turhaa: yksi kysely, muutama aikaehdotus, ei tilejä vastaajille.

## Toiminnallisuus (tavoite)

- Luo kysely: otsikko, kuvaus, lista aikaehdotuksia
- Jaa julkinen linkki (satunnainen tunniste, ei kirjautumista)
- Vastaajat merkitsevät jokaiseen ehdotukseen: sopii / ei sovi / ehkä
- Yhteenvetonäkymä: mikä aika saa eniten ääniä
- Kyselyn lukitseminen ja lopullisen ajan valinta
- Suomeksi, aikavyöhyke Europe/Helsinki

## Rajaukset

- Ei kalenteri-integraatioita ensimmäisessä versiossa
- Ei sähköposti-ilmoituksia
- Ei tiimejä, työtiloja eikä maksuja
